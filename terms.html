도구로 돌아가기

제품과 사용권

구매자는 결과물을 상업적으로 쓸 수 있습니다.

DetailCut은 사용자가 권리를 가진 이미지를 브라우저에서 분할하는 독립 소프트웨어입니다. 개인 등급은 15,000 sats이며 사용자 1명, 팀 등급은 100,000 sats이며 하나의 법인 조직 안에서 기명 사용자 최대 10명에게 허가됩니다. 두 등급은 같은 완성된 Pro ZIP을 받으며 라이선스 범위만 다릅니다. 프로그램으로 만든 결과물은 상품 판매 등 상업적 목적으로 사용할 수 있습니다.

Pro 프로그램 원본이나 수정본을 제3자에게 재판매·재배포·공유하거나, 타인의 이미지·상표·저작권을 침해하는 용도로 사용할 수 없습니다. 구매자가 입력 이미지와 게시 결과에 필요한 권리를 확인해야 합니다.

기능과 한계

자동 경계는 검토를 대신하지 않습니다.

도구는 목표 높이 부근에서 시각 변화가 비교적 적은 행을 찾고, 빈틈이나 중복 없이 조각을 만듭니다. 이미지의 의미, 쇼핑몰 심사 기준, 등록 성공을 보장하지 않습니다. 브라우저·기기 메모리와 Canvas 한계 때문에 매우 큰 파일은 실패할 수 있습니다. 게시 전에 모든 경계를 직접 확인하세요.

지원과 환불

재현되는 다운로드·실행 문제를 해결합니다.

구매 후 7일 안에 다운로드 또는 실행 문제가 재현되면 구매자 전용 비공개 저장소의 이슈로 알려주세요. 문제를 합리적으로 해결할 수 없으면 구매자가 제공한 호환 Lightning 인보이스로 결제 sats를 반환합니다. 공개 이슈에는 이미지 원본, 주문정보, 이메일 또는 결제 증빙을 올리지 마세요.

강행 소비자보호 규정과 결제 제공자의 구매자 약관이 이 안내보다 우선합니다. 단순한 자동 경계 선호 차이 또는 제3자 쇼핑몰의 등록 거절은 기능 결함으로 보장하지 않습니다.

개인정보

무료 도구에는 업로드·분석 추적 경로가 없습니다.

무료 도구는 이미지, 파일명, 설정값을 서버로 보내거나 저장하지 않습니다. 자체 분석도구, 쿠키, 계정 시스템도 없습니다. Pro 주문 요청용 GitHub 이슈는 공개되므로 개인정보, 이미지, 주문 정보, 결제 증빙이나 비공개 링크를 작성하지 마세요. 요청 자체는 결제가 아닙니다.

판매자가 공개 이슈에서 재고와 조건을 확인한 뒤 선택한 등급에 맞는 이슈 전용 일회용 Lightning 인보이스를 30분 결제 기한과 함께 안내합니다. 구매자는 조건을 수락한 뒤에만 결제합니다. 판매자는 반환된 상태 주소로 공개 결제 증빙 없이 정산 여부를 확인합니다. 결제 확인 후 영업일 1일 안에 이슈 작성자의 GitHub 계정을 구매자 전용 비공개 저장소에 초대하고, 그 저장소에서 라이선스 ZIP과 SHA-256 해시를 제공합니다. Lightning 네트워크와 Stacker News에는 각각의 약관과 개인정보 처리가 적용됩니다.
